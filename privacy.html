1. 판독기 본 기능

  • 붙여넣은 리딩, 평소 말투, 카드 이름, 덱 이름, 카드·덱 사진은 이용자의 브라우저 안에서만 분석하고 서버로 보내거나 저장하지 않아요.
  • "기억하기", "가르쳐 주기", 게시판 로그인 유지 정보는 이용자의 브라우저 저장소(localStorage)에만 저장돼요. 사진 원본은 저장하지 않고 색·무늬 요약값만 저장해요. 브라우저의 사이트 데이터 삭제나 화면의 "지우기" 버튼으로 언제든 지울 수 있어요.
  • 예외: 이용자가 직접 동의하고 "덱 자동 검색"을 누른 경우에만, 고른 카드 사진을 작게 줄여 아래 3번의 외부 검색 서비스로 보내요. 사이트 서버는 이 사진을 저장하지 않아요.

4. 이용자의 권리

  • 내 정보의 열람·정정·삭제·처리정지를 요청할 수 있어요.
  • 내가 쓴 글이나 나에 관한 글: 각 글의 삭제 요청 · 정정 요청 버튼으로 요청해 주세요. 로그인하지 않아도 돼요.
  • 숨김·반려된 내 글: 게시판의 내가 쓴 글 · 이의제기에서 작성 계정 또는 글별 확인키로 확인 후 재검토를 요청할 수 있어요. 사유·답변은 작성자와 운영자만 볼 수 있어요.
  • 비로그인 글 확인키는 브라우저에 최근 50개까지 보관하며, 내 글 조회·이의제기 시 HTTPS 요청 본문으로 이 사이트 서버에 전달해요. 서버에는 원문 대신 해시만 저장해요. URL·공개 목록에는 포함하지 않아요. 사이트 데이터 삭제 시 키도 지워지므로 필요한 키는 미리 보관해 주세요.
  • 교정 제안은 운영자 확인 후 예시·설명·집계·검토 사유가 공동 검토에 공개돼요. 리딩 원문을 자동 전송하지 않아요. 제안자·투표자 ID와 복구키는 공개하지 않으며, 기여자 순위 닉네임 공개는 별도로 선택·철회할 수 있어요. 브라우저에 복구키를 보관하며 직접 보관한 키로 다른 브라우저에서도 이어서 참여할 수 있어요. 가르치기 화면의 참여 정보 삭제로 닉네임·제안·투표를 삭제할 수 있어요. 이미 공개된 화면의 외부 복사본은 회수하기 어려울 수 있어요.
  • 분석 이용 횟수는 예시를 제외하고 이용자가 직접 입력한 뒤 분석할 때 집계해요. 본문은 보내지 않고 무작위 중복방지키만 보내요. 입력 영역의 이용 횟수 집계하지 않기로 이후 집계를 끌 수 있어요. 방문자·고유인 수나 정확도가 아닌 단순 이용 집계예요.
  • 제보용 이메일 정보: 게시판 글쓰기 칸의 탈퇴(이메일 정보 삭제) 버튼으로 바로 지울 수 있어요.
  • 브라우저에 저장된 정보: 화면의 "지우기" 버튼이나 브라우저의 사이트 데이터 삭제로 지울 수 있어요.

5. 만 14세 미만 아동

이메일 인증이 필요한 제보는 만 14세 이상만 쓸 수 있어요. 만 14세 미만이 인증한 사실을 알게 되면 해당 정보를 지체 없이 삭제해요.

6. 안전성 확보 조치

  • 이메일·IP·인증 코드는 원래 값 대신 비밀키로 바꾼 값을 저장 경로·비교에 써요. 이메일 원문은 계정 확인에만 쓰고 공개하지 않아요.
  • 저장소는 비공개(Private)로 설정하고, 운영자 화면은 별도 비밀번호로 보호해요. 모든 통신은 HTTPS로 암호화돼요.

7. 개인정보 보호책임자와 문의

개인정보 보호책임자: 사이트 운영자. 개인정보 문의·불만·피해 구제는 게시판 각 글의 삭제 요청 · 정정 요청이나 게시판 피드백으로 보내 주세요. 운영자가 확인 후 답변해요.

개인정보 침해 신고·상담: 개인정보침해신고센터(국번 없이 118, privacy.kisa.or.kr), 개인정보분쟁조정위원회(1833-6972, kopico.go.kr), 대검찰청(1301), 경찰청 사이버범죄 신고시스템(ecrm.police.go.kr).
